Qué cambia en “mejorado”: expresividad subida (noise_w 0.95, que rompe la cadencia de metrónomo), menos grave de caja, realce de presencia en 3.2 kHz, eses domadas, compresión para nivelar sílabas y normalización a −16 LUFS.

Para aplicarlo, en perfiles/<id>/perfil.json:

"voz": {
  "proveedor": "piper",
  "modelo": "../../bin/voces/es_MX-claude-high.onnx",
  "velocidad": 1.0,
  "expresividad": 0.95,
  "variacion": 0.72,
  "procesar": true,
  "presencia": 3.5
}

Para usar Kokoro, que ya está instalado:

"voz": {
  "proveedor": "kokoro",
  "modelo": "em_alex",
  "velocidad": 1.0,
  "procesar": true
}

Voces disponibles: em_alex y em_santa (masculinas), ef_dora (femenina). Tarda unas dos veces el tiempo real frente a las diez de Piper, pero en un video de varios minutos veinte segundos más de síntesis no cambian nada.
